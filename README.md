# HarzGram Social Hub

Build a responsive frontend for a mini social media app called “HarzGram”.

Use HTML, CSS, and JavaScript for the frontend. Create a clean, friendly interface with:

- A sign-up and login screen

- A home feed with posts, author profiles, timestamps, and like/comment controls

- A form to create a post

- User profile pages with bio, posts, follower count, and following count

- Follow and unfollow buttons

- A comments view for each post

- Navigation between the feed, profile, and search/discover pages

Use realistic sample data and make the interface interactive. For now, do not connect a database or add a backend. Keep the frontend organized so I can connect it later to a REST API from a separate backend in VS Code. Put API requests in a clearly separated service/helper file and use a configurable base URL.
